# 비판적 사고

주장의 근거·추론·맥락을 평가하고 자신의 판단을 수정하는 사고.

## 판단을 점검하는 사고
**비판적 사고**(Critical Thinking)는 주장을 이해하고 근거를 평가하며, 자신의 판단도 수정하는 성찰적 활동이다. 상대의 잘못을 찾아내거나 어떤 주장에도 반대하는 태도와는 다르다. 델파이 보고서는 이를 목적을 가진 자기조절적 판단으로 설명하며 해석·분석·평가·추론·설명·자기조절을 핵심 기능으로 제시한다.[^delphi]

## 무엇을 분석하는가
논의를 읽을 때 목적과 현안 문제, 핵심 개념, 가정, 정보, 추론과 결론을 나눈다. 같은 사실도 관점과 맥락에 따라 의미가 달라지므로, 예상되는 귀결과 대안도 확인한다.

가상의 대학이 출석 의무를 강화하려 한다면 “출석률을 높이는가”와 “학습을 개선하는가”는 다른 질문이다. 출석과 성적의 상관관계만으로 의무 강화의 효과를 확정할 수 없고, 건강·돌봄·장애 등 예외 상황도 고려해야 한다.

## 평가 기준
| 기준 | 점검할 질문 |
| --- | --- |
| 분명함·정밀함 | 용어가 여러 뜻이거나 적용 경계가 불분명하지 않은가? |
| 정확성 | 제시한 사실을 확인할 자료가 있는가? |
| 적절성·중요성 | 근거가 실제 쟁점과 연결되는가? |
| 깊이·폭넓음 | 어려운 조건과 다른 관점을 고려했는가? |
| 논리성·충분성 | 결론이 전제의 지지 범위를 넘지 않는가? |
| 공정성 | 자기 주장에도 같은 기준을 적용하는가? |

## 의견 차이의 종류
사실적 대립에는 자료 확인, 언어적 대립에는 의미 구분이 필요하다. 해석의 대립에는 설명의 비교, 가치의 대립에는 우선순위와 정당화의 검토가 필요하다. 모든 다툼을 사실 하나로 해결하거나 단순 취향으로 돌려서는 안 된다.

## 창의성과 시간의 관점
대안을 만들어 내는 창의적 사고와 대안을 검토하는 비판적 사고는 함께 작동한다. 단기 편익과 장기 피해를 어느 기간까지 볼지도 드러내야 한다. 시간관과 가치관은 전제와 평가 기준에 영향을 주지만, 동일한 전제와 의미를 고정한 논증의 형식적 타당성이 개인 취향에 따라 바뀌는 것은 아니다.
