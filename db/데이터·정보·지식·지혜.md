# 데이터·정보·지식·지혜

기록에 맥락과 해석을 더해 판단으로 연결하는 개념적 구분.

## DIKW
**DIKW**는 Data, Information, Knowledge, Wisdom의 약자다. 관찰된 기록에서 맥락 있는 정보, 설명과 활용 능력, 가치와 상황을 고려한 판단으로 이어지는 차이를 설명하는 비유적 틀이다.

| 단계 | 가상의 매장 예시 |
| --- | --- |
| 데이터 | 시간별 판매 건수 기록 |
| 정보 | 특정 시간대의 판매량이 반복적으로 높다는 요약 |
| 지식 | 고객 흐름·행사·인력과 판매 패턴의 관계를 이해함 |
| 지혜 | 직원 부담과 고객 접근성까지 고려해 운영을 결정함 |

## 자동적인 계단은 아니다
데이터를 많이 모으면 지혜가 자동으로 생기는 것은 아니다. 측정 오류·표본 편향·정의의 차이가 있으며, 같은 정보도 목적에 따라 다르게 해석된다. 이 틀은 엄밀한 자연법칙이나 모든 연구자가 공유하는 단일한 분류는 아니다.

## 조직의 문제
부서마다 고객이나 매출을 다르게 정의하면 같은 데이터베이스를 보고도 다른 결론을 낼 수 있다. 맥락·용어·품질을 관리하고 해석을 검토할 사람이 필요하다.

## 윤리적 판단
무엇이 효과적인지 안다고 무엇을 해야 하는지까지 결정되는 것은 아니다. 개인정보나 차별 문제처럼 목적과 수단의 정당성을 별도로 판단해야 한다. 데이터 활용역량은 도구 사용뿐 아니라 질문·가정·한계를 설명하는 능력도 포함한다.
