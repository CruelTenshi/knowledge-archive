# 인공지능

규칙 기반 방법부터 데이터 학습과 콘텐츠 생성까지 포함하는 기술적 개념.

{{틀:data-ai}}

## 용어의 관계
**인공지능**(AI)은 입력을 바탕으로 예측·추천·결정·콘텐츠 같은 출력을 만들어 내는 시스템을 포함하는 넓은 분야다. 모든 AI가 데이터 학습만으로 작동하는 것은 아니다. 규칙 기반 전문가 시스템도 AI의 역사에 포함된다.

**머신러닝**(ML)은 데이터로부터 패턴을 학습하는 접근이고, **딥러닝**(DL)은 다층 신경망을 활용하는 머신러닝의 한 계열이다. **생성형 AI**는 새로운 형태의 콘텐츠를 생성하는 목적의 기술을 말하며, AI·ML·DL과 완전히 같은 기준의 분류는 아니다.

## 학습과 사용
학습에서는 데이터와 목표에 따라 모형의 매개변수를 조정한다. 추론에서는 학습된 모형과 입력을 활용해 출력을 만든다. 입력할 때마다 모형 자체가 자동으로 재학습되는 것은 아니다.

## 활용
스팸 분류, 수요 예측, 추천, 문서 초안 생성처럼 다양한 과제가 있다. 언어모형의 유창한 문장이 사실성이나 이해의 정확성을 보장하지는 않는다.

## 평가
어떤 과제를 어떤 자료·조건에서 수행하는지 정하고 정확성·안전·편향·비용·지연을 함께 평가한다. AI의 의식 여부 같은 철학적 논쟁과 특정 시스템의 관찰 가능한 업무 성능은 구분해야 한다.

## 학습 문제의 구분
지도학습은 입력과 목표값의 사례로 예측 관계를 배우고, 비지도학습은 정답표 없이 자료의 구조를 찾는다. 강화학습은 행동 뒤의 보상을 통해 정책을 개선한다. 자기지도학습은 데이터의 일부를 가리거나 다음 요소를 맞히는 방식으로 데이터 자체에서 학습 목표를 구성한다.

학습자료의 성능과 새 상황의 성능은 다를 수 있다. 외운 패턴이 아닌 일반화 능력을 보려면 독립적인 평가자료가 필요하고, 실제 사용에서는 입력 분포와 업무 조건의 변화도 관찰해야 한다. 생성모형의 출력 품질과 사실성은 별도로 평가한다.

## 규칙, 학습, 생성의 차이
직접 만든 규칙은 ‘거래액이 100만 원 이상이고 새 기기이면 확인’처럼 기준이 명시적이다. 학습 모형은 과거 자료에서 거래액, 접속 시간, 기기 변경이 사기 여부와 맺는 관계를 추정한다. 생성 모형은 입력 조건에 맞춰 문장이나 이미지를 만들며, 자연스러운 결과가 사실 확인까지 끝났음을 뜻하지는 않는다.

### 확률에서 운영 판단으로
사기 탐지에서 모형이 거래별 위험 점수 $s$를 내면 운영자는 문턱값 $t$ 이상인 거래를 확인 대상으로 정할 수 있다. $t$를 낮추면 더 많은 사기를 잡을 가능성이 생기지만 정상 거래를 막는 오탐도 늘 수 있다. 정상 거래가 대부분인 자료에서는 정확도 하나로 성능을 판단하기 어려우므로, 실제 사기 중 잡아낸 비율과 의심 표시된 거래 중 실제 사기 비율을 함께 본다.
